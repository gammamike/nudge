Nudge's first release brings command correction to interactive Bash 5+ on Linux.
Local rules check failed commands, show a proposed correction, and wait for Enter
before running it. Any other key cancels.

- 267 executable adapters with scoped support, including Git, Docker/Compose,
  systemd, common Linux tools, Nix, iwctl, Zellij, and strace.
- Codex, Claude Code, and local LLM fallback with configurable models.
- Per-user installation, updates, rollback, and removal; staged package layout,
  man page, and Bash completion.
- Optional Omarchy settings panel with live theme matching, provider/model
  selection, connection tests, and Bash setup instructions.

**Cloud fallback is enabled by default.** If local rules cannot choose an eligible
correction, Nudge can use your existing Codex login to ask OpenAI. Claude Code
uses Anthropic when selected; local LLM providers use a loopback server. These
requests happen before Enter-to-run confirmation. To disable all model requests,
add `export NUDGE_LOCAL_ONLY=1` to `~/.bashrc` and run it in your current shell.
See [provider setup and privacy](https://github.com/gammamike/nudge/blob/v0.1.0/docs/PROVIDERS.md).

## Install

Download the two archives and `SHA256SUMS` attached to this release. In their
download directory:

```bash
sha256sum -c SHA256SUMS
tar -xzf nudge-0.1.0-linux-x86_64.tar.gz
cd nudge-0.1.0-linux-x86_64
./install.sh
exec bash
```

The binary bundle needs Linux x86_64 and Bash 5+, with no Rust toolchain. The
installer backs up `~/.bashrc` before adding the hook. Use `--no-modify-shell` to
manage activation yourself. Run `nudge uninstall` to remove the per-user install.
Checksums detect changed downloads; they are not publisher signatures.

Source builds require Rust 1.88+ and Cargo. Local HTTP model backends require
`curl` and a separately running server. Codex and Claude Code use separately
installed CLIs with subscription logins.

## Optional Omarchy companion

```bash
omarchy plugin add https://github.com/gammamike/nudge.git --enable
omarchy-shell shell summon gammamike.nudge '{}'
```

The companion requires Omarchy Shell plugin support, `jq`, and GNU `timeout`.
Install the CLI separately first. Remove the companion with
`omarchy plugin remove gammamike.nudge`; this preserves CLI settings and the Bash
hook. [Companion setup](https://github.com/gammamike/nudge/blob/v0.1.0/docs/OMARCHY_COMPANION.md)
includes provider configuration and update instructions.

This release supports Linux and interactive Bash only. Executable-name typos,
pipelines, compound commands, aliases/functions, and unsupported or ambiguous
forms are left alone. An adapter listing does not mean every subcommand is
supported. AUR and marketplace listings are separate from this download release.
