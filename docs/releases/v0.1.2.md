Nudge is **suggested autocorrect for Linux commands**: when an eligible command
fails, it suggests a correction in your usual Bash terminal. Press **Enter** to
run it, or any other key to cancel. It helps with mistyped syntax and unfamiliar
tools while keeping you in control.

This release makes the Omarchy companion easier to understand and set up:

- **First-run welcome:** opens once after the plugin is enabled. Restarting the
  shell or updating the plugin does not repeatedly open it.
- **One setup button:** **Install Nudge & enable Bash** downloads and verifies the
  versioned Linux x86_64 release, installs it for your user, backs up and updates
  `~/.bashrc`, and adds **Nudge Settings** to Super+Space. Open a new Bash terminal
  afterward. No Rust toolchain or administrator password is needed.
- **Clearer previews:** a real command-correction example and dark/light panel
  screenshots show what Nudge does and how to configure it.

Setup is explicit. Opening the panel does not install software or make a model
request. Existing managed installations reuse their current CLI; package/custom
installations and other architectures retain their documented installation path.
If you already sourced the hook manually, remove that source line before guided
setup. Provider settings are preserved.

## Install or update the companion

New installation:

```bash
omarchy plugin add https://github.com/gammamike/nudge.git --enable
```

Existing installation:

```bash
omarchy plugin update gammamike.nudge
```

If the panel does not appear, open it with:

```bash
omarchy-shell shell summon gammamike.nudge '{}'
```

For stale cached plugin code, run `omarchy restart shell`, then reopen the panel.
The [companion guide](https://github.com/gammamike/nudge/blob/v0.1.2/docs/OMARCHY_COMPANION.md)
includes dependencies, alternative installation, and removal instructions.

## CLI downloads

The attached Linux x86_64 archive, matching source archive, and `SHA256SUMS` remain
available for installation without a desktop. Verify both archives with
`sha256sum -c SHA256SUMS`, extract the binary bundle, and run its `./install.sh`.
Nudge supports Linux with Bash 5+. Source builds require Rust 1.88+ and Cargo.

Local rules run first. **Codex cloud fallback is enabled by default**;
**Claude Code and local LLMs** are alternatives. Requests for unresolved eligible
commands happen before Enter-to-run confirmation. For local rules only, add
`export NUDGE_LOCAL_ONLY=1` to `~/.bashrc` before starting a new Bash shell.
See [provider configuration and privacy](https://github.com/gammamike/nudge/blob/v0.1.2/docs/PROVIDERS.md).
