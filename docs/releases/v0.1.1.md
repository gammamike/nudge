Nudge v0.1.1 adds an application launcher for the Omarchy companion and fixes
the scrollbar that could overlap the panel title.

- **Open from Super+Space:** in the companion's **Setup** tab, select **Add
  launcher shortcut**, then search for **Nudge Settings**. The shortcut uses
  your theme's terminal icon and opens the panel without a terminal window.
- **Explicit setup and removal:** Setup also has **Remove launcher shortcut**.
  Repeated installation is safe; edited entries and conflicting files are
  preserved. Adding a shortcut does not change the Bash hook or provider settings.
- **Scrollbar fix:** the scrollbar stays at the right edge and its thumb is
  hidden when the content fits. Larger text remains scrollable.

## Update the companion

For a companion installed through Omarchy's plugin manager:

```bash
omarchy plugin update gammamike.nudge
omarchy-shell shell summon gammamike.nudge '{}'
```

If Omarchy retains the old panel code, run `omarchy restart shell` and open the
panel again. For a manually copied development installation, update its files
from this version instead. See [companion setup](https://github.com/gammamike/nudge/blob/v0.1.1/docs/OMARCHY_COMPANION.md).

The launcher is optional: opening or updating the companion does not install it.
Remove the shortcut from Setup before removing the companion.

## Install or update the CLI

Download both attached archives and `SHA256SUMS`. In the download directory:

```bash
sha256sum -c SHA256SUMS
tar -xzf nudge-0.1.1-linux-x86_64.tar.gz
cd nudge-0.1.1-linux-x86_64
./install.sh
exec bash
```

The binary bundle supports Linux x86_64 and Bash 5+. Source builds require
Rust 1.88+ and Cargo. The CLI and Omarchy companion are installed separately;
the companion requires Omarchy Shell plugin support, `jq`, and GNU file utilities.

Provider defaults are unchanged: Codex cloud fallback is enabled by default;
Claude Code and local LLMs are alternatives. Model requests occur before
Enter-to-run confirmation. Add `export NUDGE_LOCAL_ONLY=1` to `~/.bashrc` to
disable all model requests. [Provider configuration and privacy](https://github.com/gammamike/nudge/blob/v0.1.1/docs/PROVIDERS.md)
has the full details.

The Omarchy marketplace submission is awaiting maintainer approval. Direct
repository installation is available; AUR publication remains on hold.
